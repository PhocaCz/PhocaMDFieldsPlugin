# Phoca MD Fields Plugin



Phoca MD Fields Plugin - provides a custom Markdown field for Joomla articles. Instead of using a WYSIWYG editor like TinyMCE, you write your content in pure Markdown. On saving the article, the plugin automatically converts your Markdown into clean HTML and injects it directly into the standard Joomla Introtext and Fulltext fields.
